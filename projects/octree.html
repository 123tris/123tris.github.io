八分木

初の自作C++エンジンの物理のための八分木。毎フレーム作り直し、各ボックスコライダーをそれを完全に含む最小のノードに格納します。テストシーンでは、ランダムに配置した動くコライダーで木を埋めます。

C++ · 初の自作エンジン · 2017年 · 個人開発

深さ3、ランダムなコライダー40個。2.5秒後に空のノードを非表示

分割

ルートノードはあらかじめ決めた深さまで分割します。各ノードは8つの子を持ち、子の番号は3ビットで八分空間を表します。4が上半分、2が右半分、1が奥半分です。各ビットに応じて子の中心を親のサイズの4分の1だけその軸方向にずらし、子のサイズは親の半分です。

void OctNode::subDivide(int depth)
{
    subNodes = std::vector<OctNode*>(8);
    for (int i = 0; i < subNodes.size(); ++i)
    {
        Vector3 newPos = position;
        if ((i & 4) == 4)
            newPos.y += size * 0.25f;
        else
            newPos.y -= size * 0.25f;

        if ((i & 2) == 2)
            newPos.x += size * 0.25f;
        else
            newPos.x -= size * 0.25f;

        if ((i & 1) == 1)
            newPos.z += size * 0.25f;
        else
            newPos.z -= size * 0.25f;

        subNodes[i] = new OctNode(newPos, size * 0.5f);
        subNodes[i]->parent = this;
        if (depth > 0) subNodes[i]->subDivide(depth - 1);
    }
}

挿入

木は毎フレーム作り直します。古い木を削除し、新しいルートを分割して、すべてのコライダーを挿入し直します。コライダーは、AABBの両端の点を含む子ノードへ降りていきます。どの子にも収まらない場合は現在のノードに残るので、境界をまたぐコライダーは木の上の方に格納されます。

デバッグ表示では、コライダーを持つノードを緑、空のノードを青、コライダーを赤で描きます。Fで空のノードの表示を切り替え（映像では2.5秒後）、J/Kで描画する深さを変えます。このバージョンは木の構築と表示までで、木を使う衝突判定のクエリは実装していません。

void OctNode::addCollider(BoxCollider* collider)
{
    if (isLeaf())
    {
        colliders.push_back(collider);
        return;
    }
    OctNode* foundNode = nullptr;
    for (OctNode* node : subNodes)
    {
        AABB nodeAABB = node->getBoundary();
        //Continue if it doesn't find
        if (!nodeAABB.AABBvsPoint(collider->aabb.min) ||
            !nodeAABB.AABBvsPoint(collider->aabb.max)) continue;
        foundNode = node;
    }
    if (foundNode == nullptr) colliders.push_back(collider);
    else foundNode->addCollider(collider);
}
