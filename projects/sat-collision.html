SATによる衝突判定

Unityの物理を使わない小さな物理ループ。重力をもつ独自のリジッドボディと、分離軸定理に基づく箱同士の衝突判定。

C# · Unity · 2016年 · 個人開発

軸に平行な箱の重なり判定

軸に平行な箱では、分離軸定理はx・y・zの3つの区間判定になります。どれか1つの軸で範囲が重ならなければ、2つの箱は離れています。各箱は自分の位置とBoxColliderのサイズから範囲を求めます。

物理マネージャーが毎フレームすべてのリジッドボディを静的なオブジェクトと判定し、重なったら速度を反転します。リジッドボディ自体はFixedUpdateで重力と速度を積分するだけです。映像では上の箱が下の箱に落ち、上へ跳ね返されます。

public bool AABBvsAABB(AABB a)
{
    // Exit with no intersection if separated along an axis
    if (max.x < a.min.x || min.x > a.max.x) return false;
    if (max.y < a.min.y || min.y > a.max.y) return false;
    if (max.z < a.min.z || min.z > a.max.z) return false;
    // No separating axis found, so the boxes overlap
    return true;
}

// PhysicsManager.Update()
foreach (CustomRigidbody rb in Rigidbodies)
{
    foreach (GameObject o in GameObjects)
    {
        if (rb.GetComponent<AABB>().AABBvsAABB(o.GetComponent<AABB>()))
            rb.velocity *= -1;
    }
}
