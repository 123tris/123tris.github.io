ゲームAI

ノードグラフ上で動く木こりのエージェント。次の行動は有限ステートマシンが決め、ノード間の経路はA*で求めます。

C# · GXPEngine · 2016年 · 個人開発

ステートマシン

各状態は独自のUpdateを持つクラスです。睡眠状態は、木が残っていれば探索状態に移ります。探索状態は最初に見つかった木のあるノードまでの経路を計画し、到着すると木を取り除いて帰宅状態に切り替えます。帰宅状態はノード0までの経路を計画し、到着すると再び探索状態に戻ります。

映像では、エージェント（小さな緑の四角）が家から水色の木のノードへ歩き、木を切って（ノードが青になる）家に戻ります。

// SearchWoodState
public override void Update()
{
    if (_agent.lastNode == _treeTarget)
    {
        _treeTarget.hasTree = false;
        _treeTarget.SetColor(System.Drawing.Color.Blue);
        _agent.SetState(new ReturnHomeState(_agent, _world));
    }
}

A*による経路探索

オープンリストは、そこまでのコストとゴールまでの直線距離の和で並べ替えます。リストから取り出したノードは確定し、現在のノードを経由する方が安い場合は隣接ノードのコストと親を更新します。ゴールが取り出されたら親をたどってスタートまで経路を復元し、エージェントはそれをウェイポイントのリストとして受け取ります。
