ゲームアーキテクチャ

Windows Formsの小さなゲームループをコンポーネント中心に組み直したもの。各ゲームオブジェクトはコンポーネントのリストを持ち、ループは入力・物理・描画の各処理で、すべてのオブジェクトにその種類のコンポーネントを問い合わせて実行します。

C# · Windows Forms · 2016年 · 個人開発

型によるコンポーネントの取得

GetComponentはオブジェクトが持つ型Tの最初のコンポーネントを返します。ループは入力と物理を毎秒144回の固定頻度で更新し、ウィンドウの再描画時に描画します。各処理は、該当するコンポーネントを持つすべてのオブジェクトでそのコンポーネントを呼びます。

映像では、Pastry（カップケーキ）がウィンドウの中心に引き寄せられてその周りを回り、BjornがPastryを追いかけます。どちらの動きも入力コンポーネントによるもので、物理コンポーネントは速度を位置に加えるだけです。

public T GetComponent<T>() where T : Component
{
    return Components.OfType<T>().Select(component => component).FirstOrDefault();
}

private void UpdatePhysics()
{
    foreach (GameObject gameObject in GameObjects)
        gameObject.GetComponent<PhysicsComponent>()?.Update(gameObject);
}

private void UpdateInput()
{
    foreach (GameObject gameObject in GameObjects)
        gameObject.GetComponent<InputComponent>()?.Update(gameObject);
}
