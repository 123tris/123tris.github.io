ゲーム物理

一から書いたベクトルクラスを土台にした2D物理。スリングショットのように飛ばしたボールが重力で落ちて壁で跳ね返り、戦車はベクトルの角度で進む向きと砲塔の向きを決めます。

C# · GXPEngine · 2016年 · 個人開発

壁との衝突

毎ステップ、速度に重力を加え、位置に速度を加えます。ボールが壁を越えた場合は、そのステップのうち壁を越えた割合だけ速度の逆方向に戻し、壁の中ではなく衝突点から跳ね返るようにしています。その後、壁に向かう速度成分を反転します。

ボールをドラッグすると距離の平方根に比例して引き戻され、離すと逆向きに発射されて重力が有効になります。赤い線は毎フレームの前の位置から現在位置までの軌跡、緑の矢印は速度です。

public void Step()
{
    oldPosition = _position.Clone();
    _velocity.Add(gravity);
    _position.Add(_velocity);

    // Left wall (the other three work the same way)
    if (_position.x - _radius < 100 && _velocity.x < 0)
    {
        // fraction of this step that went past the wall
        float ratio = (-_position.x + 100 + _radius) / (oldPosition.x - _position.x);
        _position.Add(_velocity.Clone().Scale(-ratio));

ベクトルの角度による操作

戦車の速度ベクトルは車体と一緒に回転させるので、常に車体の向きに進みます。砲塔は子スプライトで、戦車からマウスへのベクトルの角度から車体の回転を引いた角度を向きます。弾は砲塔の角度を受け取り、砲身の前に生成されます。
