エディターの研究

エンジンのエディター作りに関する研究と試作。即時モードと保持モードのUIの比較、Vulkan上のDear ImGuiによるアセットブラウザー、JSONシリアライズのための型の登録。成果はTristeonのエディターに使いました。

C++ · Dear ImGui · Vulkan · 2017年 · 個人開発

即時モードと保持モード

即時モードのUIでは、ウィジェットは毎フレーム呼ぶ関数で、描画と入力の結果の取得を一度に行います。パネルを隠すには呼ばなければよいだけです。保持モードのUIでは、ウィジェットを一度オブジェクトとして作り、コールバックやイベントで変更します。試作とTristeonのエディターは即時モードのライブラリDear ImGuiを使っています。

アセットブラウザーはプロジェクトのAssetsフォルダーを走査し、左にフォルダーツリー、右に選択したフォルダーの中身を表示します。

型の登録

C++にはリフレクションがないため、デシリアライザーは型名だけではオブジェクトを生成できません。シリアライズ可能な型はそれぞれ、名前をキーとして静的マップにファクトリー関数を登録し、デシリアライズ時は名前でファクトリーを引いて呼び出します。Tristeonのリフレクションも同じ構造です。

template <typename T> Serializable* CreateInstance() { return new T; }

struct TypeRegister
{
    using TypeMap = std::map<std::string, Serializable*(*)()>;

    static Serializable* createInstance(const std::string& s)
    {
        const auto it = getMap()->find(s);
        if (it == getMap()->end())
            return nullptr;
        return it->second();
    }

    inline static TypeMap* getMap()
    {
        static TypeMap instance;
        return &instance;
    }
};

template <typename T>
struct DerivedRegister : TypeRegister
{
    DerivedRegister(const std::string& s)
    {
        getMap()->emplace(s, &CreateInstance<T>);
    }
};
