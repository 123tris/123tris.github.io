Luaスクリプト

SFMLを使ったC++プログラムで、すべてLuaで書いたポイント＆クリックのアドベンチャーを動かします。C++側は描画・ボタン・部屋の切り替えだけを提供し、部屋・アイテム・ドラゴンはLuaで書いています。

C++ · Lua 5.3 · SFML · 2017年 · 個人開発

C++メソッドのバインド

LuaはCの関数しか呼べないため、各メソッドはテンプレートを通して登録します。テンプレートはLuaステートのextra spaceからパーサーのオブジェクトを取り出し、そのメンバー関数を呼びます。ホストはimage・button・visitを登録し、毎フレーム現在の部屋と同じ名前のLua関数を呼びます。

template <int (LuaParser::*func)(lua_State* L)>
int dispatch(lua_State* L)
{
    // the LuaParser instance is stored in the state's extra space
    LuaParser* ptr = *static_cast<LuaParser**>(lua_getextraspace(L));
    return (*ptr.*func)(L);
}

void LuaParser::setup()
{
    lua_pushcfunction(lua, &dispatch<&LuaParser::image>);
    lua_setglobal(lua, "image");
    lua_pushcfunction(lua, &dispatch<&LuaParser::button>);
    lua_setglobal(lua, "button");
    lua_pushcfunction(lua, &dispatch<&LuaParser::visit>);
    lua_setglobal(lua, "visit");
}

void LuaParser::step()   // called once per frame
{
    lua_getglobal(lua, currentFunction);
    int result = lua_pcall(lua, 0, 0, 0);
    CheckError(result)
}

Luaで書いたゲーム

各部屋は画像を描いてボタンを判定するLua関数で、visitで次のフレームから実行する関数を切り替えます。剣を持っているかどうかなどの状態はスクリプトのグローバル変数なので、ホストを再コンパイルせずにゲームを変更できます。ドラゴンの上下の揺れもスクリプト内のsinです。

function hallway()
    image("empty_room.png", 0, 0)
    if button("door_orange.png", 222, 228) then
        visit("dragonroom")
    end
    if button("door_green.png", 445, 226) then
        visit("closetroom")
    end
end

function dragonroom()
    image("empty_room.png", 0, 0)
    time = time + 1
    if monsterIsDead == false then
        if button("dragon.png", 0, math.sin(time*0.1)*25) then
            if hasSword then
                monsterIsDead = true
            else
                visit("dead")
            end
        end
    end
end
