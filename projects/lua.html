Luaスクリプト

SFMLを使ったC++プログラムで、すべてLuaで書いたポイント＆クリックのアドベンチャーを動かします。C++側は描画・ボタン・部屋の切り替えだけを提供し、部屋・アイテム・ドラゴンはLuaで書いています。

C++ · Lua 5.3 · SFML · 2017年 · 個人開発

C++メソッドのバインド

LuaはCの関数しか呼べないため、各メソッドはテンプレートを通して登録します。テンプレートはLuaステートのextra spaceからパーサーのオブジェクトを取り出し、そのメンバー関数を呼びます。ホストはwrite・visit・image・button・loadImageを登録してprogram.luaを読み込み、その後は毎フレーム、現在の部屋と同じ名前のLua関数を呼びます（最初はmain）。

// LuaParser.hpp
template <int (LuaParser::*func)(lua_State * L)>
int dispatch(lua_State * L) {
    //reference to class instance in lua extraspace
    LuaParser * ptr = *static_cast<LuaParser**>(lua_getextraspace(L));
    //call member function and return its result
    return (*ptr.*func)(L);
}

// LuaParser.cpp
#define CheckError(result) if (result != LUA_OK) { printError(lua); return;}

LuaParser::LuaParser() {
    lua = luaL_newstate();
    luaL_openlibs(lua);
    //store 'this' in lua extra space
    *static_cast<LuaParser**>(lua_getextraspace(lua)) = &*this;
    setup();
    int result = luaL_dofile(lua, "program.lua");
    CheckError(result);
    currentFunction = "main";
}

void LuaParser::step()
{
    lua_getglobal(lua, currentFunction);
    int result = lua_pcall(lua, 0, 0, 0);
    CheckError(result)
}

void LuaParser::setup()
{
    //binding to c++ member via 'dispatch' wrapper
    lua_pushcfunction(lua, &dispatch<&LuaParser::write>);
    //function name in lua
    lua_setglobal(lua, "write");
    ...
}

Luaで書いたゲーム

各部屋は画像を描いてボタンを判定するLua関数で、visitで次のフレームから実行する関数を切り替えます。剣を持っているかどうかなどの状態はスクリプトのグローバル変数なので、ホストを再コンパイルせずにゲームを変更できます。ドラゴンの上下の揺れもスクリプト内のsinです。

function hallway()
    image("empty_room.png", 0, 0)
    if button("door_orange.png", 222, 228) then
        visit("dragonroom")
    end
    if button("door_green.png", 445, 226) then
        visit("closetroom")
    end
end

function dragonroom()
    image("empty_room.png", 0, 0)
    if button("window.png", 389, 197) then
        if monsterIsDead == true then
            visit("win")
        end
    end
    time = time + 1
    if monsterIsDead == false then
        if button("dragon.png", 0, math.sin(time*0.1)*25) then
            if hasSword then
                monsterIsDead = true
            else
                visit("dead")
            end
        end
    else
        image("dragon_dead.png", 0, 0)
    end
end
