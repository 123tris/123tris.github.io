MIDIファイルの「エリーゼのために」、矩形波、16ビット44.1kHz（音声あり）

ポリフォニー

ポリシンセはボイスごとに1つのモノシンセを持ちます（ここでは16個）。ノートオンでは空いている最初のボイスを使い、ノートオフではそのノートを鳴らしているボイスを解放します。各出力サンプルは全ボイスの和に音量を掛け、−1〜1に収めたものです。

モノシンセは正弦波・矩形波・三角波・のこぎり波を生成します。エフェクトは任意の音源を包む形で連結できます：フィードバック付きディレイ、ローパスフィルター、ビットクラッシャー、ファズ、トレモロ。

public override double getSample()
{
    double sampleval = 0;
    for (int i = 0; i < tonesynthArray.Length; i++)
        sampleval += tonesynthArray[i].getSample();

    sampleval *= volume;
    if (sampleval > 1) sampleval = 1;
    if (sampleval < -1) sampleval = -1;
    return sampleval;
}

public override void playNote(byte notenum, byte velocity)
{
    for (int i = 0; i < playingnoteArray.Length; i++)
    {
        if (playingnoteArray[i] == -1)   // first free voice
        {
            tonesynthArray[i].playNote(notenum, velocity);
            playingnoteArray[i] = notenum;
            break;
        }
    }
}
