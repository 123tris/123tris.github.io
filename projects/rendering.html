3Dレンダリング

小さなC++/OpenGLエンジン上のカメラ処理。3つのベクトルから手で組み立てるルックアット変換と、移動しながら対象を画面に収め続けるカメラ。

C++ · OpenGL · SFML · 2016年 · 個人開発

ルックアット変換

glm::lookAtを使わず、カメラ自身が行列を組み立てます。forwardは対象からカメラへの正規化ベクトル、rightはワールドの上方向とforwardの外積、upはforward×rightです。この3つのベクトルとカメラの位置を変換行列の列にします。

カメラの挙動は毎回これを適用したうえで、カメラ自身の座標系で移動します。W/Sで対象に近づく・離れる、A/Dで横移動、Q/Eで上下。毎フレーム対象の方へ向き直りながら横に動くので、対象の周りを回ります。映像ではレンガのティーポットの周りを回っており、猿の回転は別の挙動です。

void CameraBehaviour::update(float pStep)
{
    getInput();
    glm::vec3 forward = glm::normalize(_owner->getLocalPosition() - target->getLocalPosition());
    glm::vec3 right = glm::cross(glm::vec3(0, 1, 0), forward);
    glm::vec3 up = glm::cross(forward, right);

    _owner->setTransform(
        glm::mat4(glm::vec4(right, 0), glm::vec4(up, 0), glm::vec4(forward, 0),
                  glm::vec4(_owner->getLocalPosition(), 1))
    );

    _owner->getWorldPosition();
    if (sf::Keyboard::isKeyPressed(sf::Keyboard::Key::Q)) _owner->translate(glm::vec3(0, speed, 0));
    if (sf::Keyboard::isKeyPressed(sf::Keyboard::Key::E)) _owner->translate(glm::vec3(0, -speed, 0));
    _owner->translate(glm::vec3(-inputH * speed, 0, -inputV * speed));
}
