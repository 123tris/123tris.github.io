3Dレンダリング

C++でのOpenGL。動く四角形自身の空間にチェッカー模様を描き、マウスカーソルの周りを照らすフラグメントシェーダーと、小さなエンジン用に書いた、3つのベクトルから手でルックアット変換を組み立てるカメラ。

C++ · OpenGL · GLSL · 2016年、2019年 · 個人開発

四角形がウィンドウ内を回り、光がマウスを追います。この大きさでも見えるよう、光の半径を20ピクセルから150ピクセルに広げて録画しています。

チェッカー模様とスポットライト

2019年に、2つの三角形からなる四角形を描くOpenGL 3.3のプログラムを書きました。四角形は位置・色・UVの属性を持つ頂点バッファーとインデックスバッファーから描き、経過時間から求めたoffsetのuniformでウィンドウ内を動かします。フラグメントシェーダーは四角形自身のUV空間にチェッカー模様を描くので、模様は四角形と一緒に動きます。各軸のタイル番号はUVにタイル数を掛けて切り捨てた値で、その和が偶数なら1つ目の色になります。タイル数と2つの色はC++から設定するuniformです。

光はマウスの周りの減衰です。色に「1 − カーソルまでの距離 ÷ 20」を掛けるので、カーソルの位置が最も明るく、20ピクセル離れると黒になります。GLFWはカーソルのyをウィンドウの上端から、gl_FragCoordは下端から数えるため、ホスト側でyを反転してから渡しています。

#version 330 core
out vec4 fragColor;

in vec3 vertexColour;
in vec2 UV;

uniform uvec2 tiles;
uniform vec3 tileColourA;
uniform vec3 tileColourB;
uniform vec2 mousePos;

void main()
{
    vec3 colour;
    float sum = floor(UV.x * tiles.x) + floor(UV.y * tiles.y);
    bool isEven = mod(sum,2.0) == 0.0;
    if (isEven) {
        colour = tileColourA;
    } else {
        colour = tileColourB;
    }

    vec2 difference = mousePos - gl_FragCoord.xy;
    colour *= 1-length(difference)/20;

    fragColor = vec4(colour,1);
}

ルックアットカメラ

2016年に、小さなC++エンジン用のカメラの挙動を書きました。glm::lookAtを使わず、自分で行列を組み立てます。forwardは対象からカメラへの正規化ベクトル、rightはワールドの上方向とforwardの外積、upはforward×rightです。この3つのベクトルとカメラの位置を変換行列の列にします。

void CameraBehaviour::update(float pStep)
{
    getInput();
    glm::vec3 forward = glm::normalize(_owner->getLocalPosition() - target->getLocalPosition());
    glm::vec3 right = glm::cross(glm::vec3(0, 1, 0), forward);
    glm::vec3 up = glm::cross(forward, right);

    _owner->setTransform(
        glm::mat4(glm::vec4(right, 0), glm::vec4(up, 0), glm::vec4(forward, 0),
                  glm::vec4(_owner->getLocalPosition(), 1))
    );

    _owner->getWorldPosition();
    if (sf::Keyboard::isKeyPressed(sf::Keyboard::Key::Q)) _owner->translate(glm::vec3(0, speed, 0));
    if (sf::Keyboard::isKeyPressed(sf::Keyboard::Key::E)) _owner->translate(glm::vec3(0, -speed, 0));
    _owner->translate(glm::vec3(-inputH * speed, 0, -inputV * speed));
}

対象の周りの移動

カメラの挙動は毎回これを適用したうえで、カメラ自身の座標系で移動します。W/Sで対象に近づく・離れる、A/Dで横移動、Q/Eで上下。毎フレーム対象の方へ向き直りながら横に動くので、対象の周りを回ります。映像ではレンガのティーポットの周りを回っており、猿の回転は別の挙動です。
