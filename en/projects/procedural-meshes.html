Procedural meshes

A mushroom mesh generated in code in Unity. It builds on a lathe script that revolves a 2D profile around the vertical axis, and scales the stem and the cap separately, so their widths and heights are independent inspector values.

C# · Unity · 2016 · solo

Revolving a profile

The profile is a list of 2D points, revolved around the Y axis in N slices: each slice rotates the points by slice × 360°/N and adds them as vertices, and the first slice is repeated at 360° so the texture's U coordinate runs from 0 to 1 without wrapping. For the mushroom, each vertex gets a UV from its slice and point index, the first five points are scaled as the stem and the rest as the cap, and the cap starts at the top of the scaled stem.

Stem width, stem height, cap width and cap height are independent inspector values. In the clip these values are changed while it runs: the slice count goes from 3 to 32, then the stem and cap grow, and each change rebuilds the mesh.

//generate vertices
for (int splineIndex = 0; splineIndex <= splineCount; splineIndex++)
{
    Matrix4x4 mat = Matrix4x4.TRS(Vector3.zero,
        Quaternion.Euler(0, splineIndex * 360.0f / splineCount, 0), Vector3.one);
    for (int j = 0; j < splineVertexCount; j++)
    {
        Vector3 vertex;
        if (j > 4)
        {
            float capYOffset = (_points[j].y - _points[4].y) * capHeight;
            //Cap vertice position
            vertex = new Vector3(_points[j].x * capWidth, (_points[4].y * stemHeight) + capYOffset);
        }
        else
            //Stem vertice position
            vertex = new Vector3(_points[j].x * stemWidth, _points[j].y * stemHeight);
        vertex = mat.MultiplyPoint(vertex);
        meshBuilder.AddVertex(vertex, new Vector2((float)splineIndex / splineCount,
                                                  (float)j / (splineVertexCount - 1)));
    }
}
