Procedural meshes

Meshes built in code in Unity: a mesh builder for vertices, UVs and triangles, a lathe that revolves a 2D profile around the vertical axis, and a mushroom whose shape is set from the inspector.

C# · Unity · 2016 · solo

Revolving a profile

The profile is a list of 2D points. For each of N slices the points are rotated around the Y axis by slice × 360°/N and added as vertices, with UVs from the slice and point index. The first slice is repeated at 360° so the texture's U coordinate runs from 0 to 1 without wrapping. Neighbouring slices are joined with two triangles per quad.

The mushroom scales its stem points and its cap points separately, so stem width, stem height, cap width and cap height are independent inspector values. In the clip these values are changed while it runs: the slice count goes from 3 to 32, then the stem and cap grow, and each change rebuilds the mesh.

for (int splineIndex = 0; splineIndex <= splineCount; splineIndex++)
{
    Matrix4x4 mat = Matrix4x4.TRS(Vector3.zero,
        Quaternion.Euler(0, splineIndex * 360.0f / splineCount, 0), Vector3.one);
    for (int j = 0; j < splineVertexCount; j++)
    {
        Vector3 vertex;
        if (j > 4)   // cap points
        {
            float capYOffset = (_points[j].y - _points[4].y) * capHeight;
            vertex = new Vector3(_points[j].x * capWidth, (_points[4].y * stemHeight) + capYOffset);
        }
        else         // stem points
            vertex = new Vector3(_points[j].x * stemWidth, _points[j].y * stemHeight);
        vertex = mat.MultiplyPoint(vertex);
        meshBuilder.AddVertex(vertex, new Vector2((float)splineIndex / splineCount,
                                                  (float)j / (splineVertexCount - 1)));
    }
}

for (int splineIndex = 1; splineIndex <= splineCount; splineIndex++)
{
    for (int vertexIndex = 1; vertexIndex < splineVertexCount; vertexIndex++)
    {
        int v0 = getIndex(splineIndex - 1, vertexIndex - 1, splineVertexCount);
        int v1 = getIndex(splineIndex, vertexIndex - 1, splineVertexCount);
        int v2 = getIndex(splineIndex, vertexIndex, splineVertexCount);
        int v3 = getIndex(splineIndex - 1, vertexIndex, splineVertexCount);
        meshBuilder.AddTriangle(v0, v1, v2);
        meshBuilder.AddTriangle(v0, v2, v3);
    }
}
