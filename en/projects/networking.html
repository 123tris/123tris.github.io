Networking

A TCP chat server that relays messages between several clients, each on its own thread, with a chat client in Unity.

C# · Unity · TCP · 2016 · solo

Message framing

TCP delivers a stream of bytes, so every message starts with a 4-byte length followed by the text encoded as UTF-16. The receiver reads the length first and then the message bytes.

The server accepts connections on port 6969 and starts a thread per client. Each message it receives is sent to every other connected client. In the clip the Unity client is connected together with two scripted test clients, whose replies arrive through the server.

// Server: relay to everyone except the sender
public void SendMessageToClients(string message, params HandleClient[] ignoreClients)
{
    foreach (HandleClient client in clientList)
    {
        if (!ignoreClients.Contains(client) && client.Active)
            client.SendMessage(message);
    }
}
