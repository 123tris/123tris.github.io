Lua scripting

A C++ program with SFML that runs a point-and-click adventure written entirely in Lua. The C++ side only provides drawing, buttons and switching rooms; the rooms, the items and the dragon are Lua.

C++ · Lua 5.3 · SFML · 2017 · solo

Binding C++ methods

Lua calls plain C functions, so each method is registered through a template that recovers the parser object from the Lua state's extra space and calls the member function on it. The host registers image, button and visit, and every frame it calls the Lua function named after the current room.

template <int (LuaParser::*func)(lua_State* L)>
int dispatch(lua_State* L)
{
    // the LuaParser instance is stored in the state's extra space
    LuaParser* ptr = *static_cast<LuaParser**>(lua_getextraspace(L));
    return (*ptr.*func)(L);
}

void LuaParser::setup()
{
    lua_pushcfunction(lua, &dispatch<&LuaParser::image>);
    lua_setglobal(lua, "image");
    lua_pushcfunction(lua, &dispatch<&LuaParser::button>);
    lua_setglobal(lua, "button");
    lua_pushcfunction(lua, &dispatch<&LuaParser::visit>);
    lua_setglobal(lua, "visit");
}

void LuaParser::step()   // called once per frame
{
    lua_getglobal(lua, currentFunction);
    int result = lua_pcall(lua, 0, 0, 0);
    CheckError(result)
}

The game in Lua

Each room is a Lua function that draws its images and checks its buttons; visit sets which function runs from the next frame on. State such as having the sword is a global in the script, so the game can be changed without recompiling the host. The dragon's bobbing is a sine in the script as well.

function hallway()
    image("empty_room.png", 0, 0)
    if button("door_orange.png", 222, 228) then
        visit("dragonroom")
    end
    if button("door_green.png", 445, 226) then
        visit("closetroom")
    end
end

function dragonroom()
    image("empty_room.png", 0, 0)
    time = time + 1
    if monsterIsDead == false then
        if button("dragon.png", 0, math.sin(time*0.1)*25) then
            if hasSword then
                monsterIsDead = true
            else
                visit("dead")
            end
        end
    end
end
