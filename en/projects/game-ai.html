Game AI

A woodcutter agent on a node graph. A finite state machine decides what it does next, and A* finds the route between nodes.

C# · GXPEngine · 2016 · solo

State machine

Each state is a class with its own Update. Sleeping hands over to searching while trees remain. Searching plans a path to the first node with a tree, and when the agent arrives it removes the tree and switches to returning home. Returning home plans a path to node 0 and switches back to searching on arrival.

In the clip the agent (the small green square) walks from home to each cyan tree node, cuts the tree (the node turns blue) and walks back.

// SearchWoodState
public override void Update()
{
    if (_agent.lastNode == _treeTarget)
    {
        _treeTarget.hasTree = false;
        _treeTarget.SetColor(System.Drawing.Color.Blue);
        _agent.SetState(new ReturnHomeState(_agent, _world));
    }
}

// ReturnHomeState
public override void Update()
{
    if (_agent.lastNode == home)
    {
        if (_world.GetTreeCount() > 0)
            _agent.SetState(new SearchWoodState(_agent, _world));
    }
}

A* pathfinding

The open list is sorted by the cost so far plus the straight-line distance to the goal. Nodes taken from the list are closed, and a neighbour's cost and parent are updated when the route through the current node is cheaper. When the goal is taken from the list, the path is rebuilt by following parents back to the start, and the agent receives it as a list of waypoints.
