Game AI

A woodcutter agent on a node graph. A finite state machine decides what it does next, and A* finds the route between nodes.

C# · GXPEngine · 2016 · solo

State machine

Each state is a class with its own Update. Sleeping hands over to searching while trees remain. Searching plans a path to the first node with a tree, and when the agent arrives it removes the tree and switches to returning home. Returning home plans a path to node 0 and switches back to searching on arrival.

In the clip the agent (the small green square) walks from home to each cyan tree node, cuts the tree (the node turns blue) and walks back.

A* pathfinding

The routes come from a step-by-step graph search with an open and a closed list, where the open list is sorted by cost plus estimate. I turned it into A*: a neighbour's cost and parent are updated when the route through the current node is cheaper, and each neighbour's estimate is its straight-line distance to the goal. When the goal is taken from the list, the path is rebuilt from the parents and handed to the agent as waypoints.
