Tiled level loading

A loader for levels made in the Tiled map editor. Objects placed in Tiled become game objects by type, and their custom properties drive keys, doors and NPC dialogue.

C# · GXPEngine · Tiled · 2016 · solo

From TMX to game objects

The .tmx file is XML and is deserialized with XmlSerializer into classes that mirror Tiled's format. Every object becomes an item whose type is its tile ID (spawn, wall, key, NPC, door and so on), and its custom properties are copied into a dictionary. The player's collision code reads those properties: the key carries an id and a point to walk to, the door opens when the player holds a key, and the NPC shows its text property.

In the clip the player picks up the key, is walked toward the door, opens it and talks to the NPC. The messages at the top come from the properties set in Tiled.

Model-view-controller editor

A separate line editor is split into a model that owns the lines and raises an update event, a view that redraws on that event, and a controller that turns mouse and keyboard input into calls on the model. Dragging near an endpoint moves it, dragging elsewhere adds a line, Backspace deletes the lines at the selected point, and S and L save and load the drawing as XML.
