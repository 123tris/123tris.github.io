SAT collision detection

A small physics loop in Unity that doesn't use Unity's physics: custom rigidbodies with gravity, and box-against-box tests based on the separating axis theorem.

C# · Unity · 2016 · solo

Axis-aligned overlap test

For axis-aligned boxes the separating axis theorem comes down to three interval checks: the boxes are apart if their extents don't overlap on x, on y or on z. Each box takes its extents from its position and its BoxCollider's size.

A physics manager tests every rigidbody against the static objects each frame and reverses the rigidbody's velocity when they overlap. The rigidbody itself only integrates gravity and velocity in FixedUpdate. In the clip the upper cube falls onto the lower one and is sent back up.

public bool AABBvsAABB(AABB a)
{
    // Exit with no intersection if separated along an axis
    if (max.x < a.min.x || min.x > a.max.x) return false;
    if (max.y < a.min.y || min.y > a.max.y) return false;
    if (max.z < a.min.z || min.z > a.max.z) return false;
    // No separating axis found, so the boxes overlap
    return true;
}

// PhysicsManager.Update()
foreach (CustomRigidbody rb in Rigidbodies)
{
    foreach (GameObject o in GameObjects)
    {
        if (rb.GetComponent<AABB>().AABBvsAABB(o.GetComponent<AABB>()))
            rb.velocity *= -1;
    }
}
