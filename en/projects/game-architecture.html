Game architecture

A small Windows Forms game loop reorganised around components. Each game object holds a list of components, and the loop runs input, physics and drawing by asking every object for the component of that type.

C# · Windows Forms · 2016 · solo

Components looked up by type

GetComponent returns the first component of type T on an object. The loop updates input and physics at a fixed 144 times per second and draws when the window repaints; each pass calls the matching component on every object that has one.

In the clip the pastry is pulled toward the centre of the window and orbits it, and Bjorn chases the pastry. Both movements come from their input components; the physics component only adds the velocity to the position.

public T GetComponent<T>() where T : Component
{
    return Components.OfType<T>().Select(component => component).FirstOrDefault();
}

private void UpdatePhysics()
{
    foreach (GameObject gameObject in GameObjects)
        gameObject.GetComponent<PhysicsComponent>()?.Update(gameObject);
}

private void UpdateInput()
{
    foreach (GameObject gameObject in GameObjects)
        gameObject.GetComponent<InputComponent>()?.Update(gameObject);
}
