Octree

An octree for the physics of our first C++ engine. It is rebuilt every frame, and each box collider is stored in the smallest node that fully contains it. A test scene fills the tree with randomly placed, moving colliders.

C++ · our first engine · 2017 · solo

Depth 3, 40 random colliders; empty nodes hidden after 2.5 seconds

Insertion

The root node is subdivided to a fixed depth up front. Each node has eight children, indexed by three bits (up, right, back). A collider descends into the child whose bounds contain both corners of its AABB; when no child contains it, it stays in the current node, so colliders that straddle a boundary are stored higher up the tree.

The debug view draws nodes that hold colliders in green, empty nodes in blue and the colliders in red. F toggles the empty nodes (in the clip after 2.5 seconds) and J/K change the drawn depth. This version builds and draws the tree; the collision query that would use it is not implemented.

void OctNode::addCollider(BoxCollider* collider)
{
    if (isLeaf())
    {
        colliders.push_back(collider);
        return;
    }

    // Find the child that contains the whole collider
    OctNode* foundNode = nullptr;
    for (OctNode* node : subNodes)
    {
        AABB nodeAABB = node->getBoundary();
        if (!nodeAABB.AABBvsPoint(collider->aabb.min) ||
            !nodeAABB.AABBvsPoint(collider->aabb.max)) continue;
        foundNode = node;
    }

    if (foundNode == nullptr) colliders.push_back(collider);
    else foundNode->addCollider(collider);
}
