Audio programming

A software synthesizer that renders MIDI files to a WAV file, sample by sample, and plays the result back with a waveform view and a keyboard view of the notes.

C# · GXPEngine · 2016 · solo

Für Elise from a MIDI file, square wave, 16-bit 44.1 kHz (with sound)

Polyphony

The polyphonic synth owns one mono synth per voice (16 here). A note-on takes the first free voice and a note-off frees the voice playing that note. Each output sample is the sum of all voices, scaled by the volume and clamped to −1…1.

The mono synths generate sine, square, triangle and sawtooth waves. Effects wrap any sound source and can be chained: a delay with feedback, a low-pass filter, a bit crusher, fuzz and tremolo.

public override double getSample()
{
    double sampleval = 0;
    for (int i = 0; i < tonesynthArray.Length; i++)
        sampleval += tonesynthArray[i].getSample();

    sampleval *= volume;
    if (sampleval > 1) sampleval = 1;
    if (sampleval < -1) sampleval = -1;
    return sampleval;
}

public override void playNote(byte notenum, byte velocity)
{
    for (int i = 0; i < playingnoteArray.Length; i++)
    {
        if (playingnoteArray[i] == -1)   // first free voice
        {
            tonesynthArray[i].playNote(notenum, velocity);
            playingnoteArray[i] = notenum;
            break;
        }
    }
}
